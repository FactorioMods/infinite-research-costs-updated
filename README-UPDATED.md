# Infinite Research Costs Modifier: Updated

Retains configurable infinite research costs and the original settings on Factorio 2.1.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using Infinite_Research_Costs can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ Infinite_Research_Costs ](https://mods.factorio.com/mod/Infinite_Research_Costs). Original author credits and applicable license notices are retained in the source package.
